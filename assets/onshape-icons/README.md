# Onshape Icon Assets

Native feature icons from [Onshape's Icon Glossary](https://cad.onshape.com/help/Content/Home/icon_glossary.htm), the [Sketch Basics](https://cad.onshape.com/help/Content/Sketch/sketch_basics.htm) page, and Onshape's favicon. `sources.json` records the exact source URL for every image.

These are bundled for offline Rich Presence artwork; the application makes no icon-download or Onshape API requests at runtime. The original icon pixels are preserved and resized proportionally onto display cards. Icons and Onshape branding belong to their respective owners; this unofficial integration does not claim ownership or grant additional rights to these assets.
